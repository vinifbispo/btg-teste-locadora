sistema que você possa gerenciar os  empréstimos dos seus jogos. O sistema deverá permitir a  inserção/edição/exclusão de amigos e jogos, além de permitir o  gerenciamento e visualização dos seus jogos, dos amigos e qual jogo  está com quem.
